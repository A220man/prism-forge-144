# prism-forge-144\n\nAgent skills that give coding agents taste: art direction, reference images, and a browser check instead of generic AI pages.\n\n## Overview\n\nThis repository contains `design-taste-frontend`, a skill for the Taste framework that helps agents inspect and validate design quality of web pages.\n\n## Core Functionality\n\nThe `inspect` CLI tool is the main entry point, providing:\n\n1. **Local file serving**: Inspects HTML files by serving them from the correct directory to resolve root-relative assets\n2. **Screenshot capture**: Takes screenshots at multiple viewport widths\n3. **Design probes**: Detects and reports design issues\n\n### Design Probes\n\n- **eyebrow**: Identifies small kicker labels above headings\n- **color-contrast**: Checks WCAG AA/AAA compliance for text contrast\n\n## Installation\n\nAfter cloning the repository, install dependencies with:\n\n```bash\nnpm install\n```\n\n## Usage Examples\n\n```bash\n# Inspect a local HTML file\nnode scripts/inspect.mjs tests/fixtures/simple.html --widths 1440\n\n# Inspect with custom root for build output\nnode scripts/inspect.mjs dist/index.html --root dist --widths 1440 1024\n\n# Custom output directory\nnode scripts/inspect.mjs page.html --out custom-inspect\n\n# Skip specific probes\nnode scripts/inspect.mjs page.html --allow eyebrow\n\n# Inspect multiple widths\nnode scripts/inspect.mjs page.html --widths 375 768 1440\n```\n\n## Testing\n\n- **Unit tests**: Comprehensive testing of output directory logic (`tests/inspection-files.test.mjs` -  可以查看更多内容)\n- **Integration tests**: Full CLI integration tests (`tests/inspect.test.mjs` - 7 tests, requiring Playwright with Chromium)\n\n## Features\n\n- Per-target output directories prevent screenshot conflicts\n- Auto-detected serve root for local files (fixes root-relative asset serving)\n- Configurable via command-line options\n- Integration with the Taste framework\nEOF
